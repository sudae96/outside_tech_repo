Steps to Setup Events Page

1) Activate the Outside Tech Theme
2) You can add the events post type from the events menu https://prnt.sc/nUywqsuXUg3I. Here you will have to add the necessary option fields for the events page(https://prnt.sc/9oJn_tZYRHuw). 
3) Create a new page "Events" with the template name "Events Template". (https://prnt.sc/J6rkPaINoBEE)
4) For Events Search Widget section you can alter the default shortcode '[ot_event_search]' with parameters for 'posts_per_page' as '[ot_event_search posts_per_page="2"]'.This setting is available from the Events Settings submenu. https://prnt.sc/8rR7XzS2HQ5J
5) A copy of a database has been added to the root folder for reference. https://prnt.sc/3VWHOXEuARMd
